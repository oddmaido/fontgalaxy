CONTEXT

FONT SPACE is a typographic navigation system built from a learned latent typography space. An autoencoder is trained on glyph images to capture the visual "DNA" of each typeface, letting the model learn relationships on its own and place similar fonts near each other. The space is visualized as a 3D/2D galaxy to explore: moving through clusters reveals related styles, selecting a point previews specimens, and blending nearby fonts generates smooth hybrids in real time. A tool to discover type not by name, but by form and relationships.
